# 景区资料语义

来源可以是主管部门、景区运营方或合作机构。每份原件有来源、字段说明与摘要，产品修订引用原件，交付时按领取方、用途和来源辖区核对许可。受理人员应能区别来源事实、内部编排和已交付凭据。

当前项目围绕游客服务反馈的授权用途治理开展资料协作。正式公告、复核观察和运营材料各有发布主体；示例记录不代表真实景区状态。

反馈原件按来源登记，授权用途、删除请求与身份遮蔽方式因来源而异。脱敏材料是原件的派生版本，记录遮蔽方式并逐版本编号；评级引用把复核结论绑定到具体原件、脱敏版本、授权版本与规则版本。授权可以收窄或撤销：收窄后未来摘要不得再引用原文，撤销或原件撤回后反馈不再可用，但历史已发布结论始终能还原当时使用的证据版本与处理依据。同一反馈经多个平台转送时，各来源的原件与授权各自独立，不因文本相似而合并。
